# Конфигурация учёта времени пилота

## Категории (фиксировать на 2–3 недели, не менять)

| Категория | Что входит |
|-----------|-----------|
| Работа — КИСУ | Проектные задачи, встречи, документация |
| Работа — собственные системы | Экзокортекс, бот, администрирование среды |
| Управление проектами | Стратегирование, планирование, отчёты |
| Развитие | Pack, curriculum, изучение, метод |
| Спорт | Тренировки, прогулки, восстановление |
| Семья | Время с семьёй |
| Быт | Еда, дорога, уход за собой, хозяйственные дела |
| Телефон / развлечения | Соцсети, видео, игры, прокрастинация |
| Сон | Ночной сон, дневной отдых |
| Прочее | Не вошедшее в категории |

## Правила ведения

1. Записывать в моменте, если понял, что прошёл ориентировочно полчаса. Не следишь за таймером — если захотел записать, записываешь.
2. Интервалы от 30 минут — мельче съедает внимание.
3. Заполнять всё время, включая «пустые» и телефон.
4. Один день — одна запись. Если пропустили день — помечать.
5. Вести в табличном виде: день, категории, время в часах.
